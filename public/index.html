接口 说明
/api/favicon?domain_url=域名 通过 query 参数获取
/api/favicon/域名 通过路径参数获取
/api/favicon?domain_url=域名&size=尺寸 指定输出图标尺寸（16-512），默认原始尺寸
/api/info?domain_url=域名 获取缓存状态等信息

特性

  • 多源回退：网站 HTML 解析 → /favicon.ico → Clearbit → DuckDuckGo → 默认图标
  • 文件缓存：首次获取后缓存 7 天，后续请求秒返回
  • 浏览器缓存：响应头 Cache-Control 1 天
  • 国内直连：无需代理
